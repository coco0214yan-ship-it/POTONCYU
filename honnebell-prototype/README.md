# 本音ベル 静的プロトタイプ

## 目的

「本音ベル」は、就職活動・AIに仕事を奪われる不安・将来不安などを、友だちと本音で話し始める体験に変えるブラウザアプリの試作品です。

外部AI APIやログインは使わず、`app.js` 内のカテゴリ別テンプレートとキーワード判定で、AIっぽい提案を返します。

## 起動方法

サーバーなしで開く場合:

1. `honnebell-prototype/index.html` をダブルクリックする
2. ブラウザで画面が開く

Node.js が使える場合:

1. PowerShellでこのフォルダを開く
2. `node server.js` を実行する
3. ブラウザで `http://127.0.0.1:4173/` を開く

## 使い方

1. 今の不安を短く入力する
2. 不安の種類を選ぶ
3. 「本音ベルを鳴らす」を押す
4. 生成された言葉をコピーして、友だちに送る
5. 入力例ボタンを押すと、すぐに試せる

## Good Design New Hope Award 向けの見せ場

- 若者の未来不安を、個人の悩みではなく社会的テーマとして扱う
- AI時代のキャリア不安を、AIで解決するのではなく、人との会話をひらく方向に使う
- ポケベルや深夜ラジオのような短い通信文化を、現代の友人関係に再解釈する
- 「本音」と「余白」を、短文・声に出すセリフ・3分トークの問いとしてUIに落とし込む
- 最小機能でも、使った人が誰かに送ってみたくなることを重視する

## 次に実装するとよい機能

- 生成された言葉を画像カードとして保存する
- 友だちに送る前に、重さを「軽め・普通・深め」で調整する
- 声に出すセリフを録音して、短いポッドキャスト風に残す
- 複数人で同じ問いを見ながら3分だけ話す画面を作る
- 応募用に、体験の流れを1分で見せるデモ動画を作る

# ぽとんちゅのプレビュー

URL: https://coco0214yan-ship-it.github.io/POTONCYU/preview/

2026-11-12の改善版です。本番の色・フォント・ガチャの見た目を引き継ぎ、操作の流れだけをプレビュー内で変更しています。Googleログイン、Firebase、AI生成、プッシュ通知は利用しません。仮の名前で試してください。

## 試し方

1. 上のURLをブラウザで開き、「プレビューをはじめる」から仮の名前を決めます。
2. 「仮の相手・グループを追加して試す」を押し、トーク一覧から相手を選びます。自分で「新しいトーク」を作ることもできます。
3. トーク下の入力欄に伝えたい思いを200字以内で書き、「一首ガチャ」を押します。この文章はトークに送られません。
4. ガチャのあと、真ん中の5音を4択から選びます。「この一首を送る」で完成した一首が届き、「もう一回まわす」で再びガチャが始まります。
5. 一首を送ると、同じトークで「おしゃべり」を送れます。「一首をつくる」でいつでも一首に戻れます。
6. 「お試し時計・通知の確認」を開き、「12時間進める」で普通の会話がロックされることを確認します。「24時間進める」で通知の見本を確認できます。

12時間の判定は **そのトークで自分が最後に送信した一首** を基準にします。相手の一首・普通の会話・ガチャの引き直しでは延長されません。ちょうど12時間でロックされ、自分が次の一首を送ると再び12時間話せます。

## お試し版でできないこと

- AIは未接続です。キーワードに対応したサンプルを使います。全行と4つの選択肢に読み仮名を持たせ、5・7・5・7・7をテストしています。未知の思いは汎用サンプルになります。
- 通知は画面内の見本です。ブラウザを閉じている間の定期通知は届きません。お試し時計はタブごとに独立しており、再読み込みで元に戻ります。
- 同じブラウザの別タブでは招待リンクで試せます。別端末との通信や永続保存はできません。会話は再読み込みで失われる場合があります。仮の相手は自動返信しません。

AIを有効にする際は、長い思いの入力・読み仮名による音数検証・真ん中の4択に対応する生成APIが必要です。本番化では12時間の送信制限をサーバー側でも確認し、24時間ごとの通知にはサーバーの定期実行と端末の通知許可を用意します。これらは未接続・未公開です。

公開版の保存キー・同期チャンネルとは分離しています。元の公開版は変更していません。

## PC内で開く

`POTONCYU` フォルダでPowerShellを開き、次を貼り付けます。追加インストールは不要です（Node.jsを使用）。

```powershell
node preview/server.cjs
```

ブラウザで `http://127.0.0.1:4280/` を開きます。停止するにはPowerShellで `Ctrl + C` を押します。

## 更新と確認

`preview/` は本番から独立しています。`node scripts/build-preview.cjs` は必要ファイルの存在確認だけを行い、本番ファイルで上書きしません。更新時は `preview/index.html` のバージョンも変えます。本番のHTML・JavaScript・Firebase設定は変更しません。

```powershell
node --test tests/chat-rules.test.cjs tests/poem-engine.test.cjs tests/reactions.test.cjs tests/ai-generation.test.cjs
```

`tests/preview-smoke.cjs` はPlaywrightがある開発環境向けの画面確認です。本番のアカウント・ルームには接続しません。

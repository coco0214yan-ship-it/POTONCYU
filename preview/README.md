# ぽとんちゅのプレビュー

URL: https://coco0214yan-ship-it.github.io/POTONCYU/preview/

現在のPC内の画面を、公開版とは別に試すためのスナップショットです。Googleログイン、Firebase、AI生成、プッシュ通知は利用しません。画面上の名前は仮の名前で入力できます。

PC内の最新版では、気持ちの自由入力、穴あき一首ガチャ、真ん中を5音の4択から選ぶ演出、送信前の余韻、一首にひもづく文章トークを試せます。全4択で五・七・五・七・七になります。時間制限なしが標準で、12時間の受付と24時間ごとの再開は任意の設定です。リアクションのUIは外しました。AI未接続のため、定型候補を表示します。同じブラウザの別タブでは招待リンクで同期できますが、別端末の人との通信はできません。お試しの一首はメモリ上だけに置き、保存しません。タブをすべて閉じると消えます。

公開版の保存キー・同期チャンネルとは分離しています。元の公開版は変更していません。

2026年10月31日の変更はPC内のみで、上記のGitHub PagesのURLにはまだ反映していません。PC内では http://127.0.0.1:4173/preview/index.html を開いてください。

更新する場合は、プロジェクトのフォルダで `node scripts/build-preview.cjs` を実行し、現在の作業中の画面・一首・時間判定のファイルをコピーします。`index.html` の読み込みURLのバージョンも更新し、プレビューのみをGitHubへ送ります。Firebaseの本番設定や秘密鍵はコピーしません。
